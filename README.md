# Aray Fitness — демо-сайт

Концепт сайта для мужского фитнес клуба Aray (Астана, Instagram @aray_fitness_astana).
Чистые HTML, CSS и JS, без сборки и внешних зависимостей.

## Файлы
- `index.html` — главная
- `club.html` — зоны клуба
- `services.html` — персональные тренировки, восстановление, советы
- `contacts.html` — адрес, WhatsApp, Instagram, 2ГИС
- `css/style.css` — оформление и анимации
- `js/main.js` — язык RU/KZ, меню, анимации. Казахские тексты лежат в списке `KZ` в начале файла, русские — прямо в HTML (атрибут `data-i18n` связывает их по ключу)
- `assets/img` — картинки, `assets/fonts` — шрифты Oswald и Onest

## Как выложить на GitHub Pages
1. Создать публичный репозиторий и загрузить в него содержимое этой папки.
2. Settings → Pages → Source: Deploy from a branch → `main`, `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `логин.github.io/имя-репозитория`.

## После продажи
- Удалить две строки, помеченные словом «ДЕМО» (meta robots в `<head>` и пометка в подвале) в каждом из четырех HTML-файлов.
- Заменить картинки на оригиналы от владельца: сейчас они вырезаны из Instagram и на большом экране нечеткие.
- Добавить часы работы и цены, когда владелец их пришлет.
